# Week 01: No Practical

There is no practical this week.
Each practical covers the lectures of the week before, and teaching starts this week.

## Getting ready

Every later practical except the second is a Jupyter notebook.
You can run them in two ways.

- Locally, with Python 3 and Jupyter installed, after cloning this repository.
- In Google Colab, through the "Open in Colab" badge at the top of each notebook, which needs no installation.

If you plan to work locally, use this week to install Python 3, Jupyter, and the packages in the root `requirements.txt`.
