# CS3033 (Artificial Intelligence) Practicals

Practical sessions for the Artificial Intelligence course at the University of Aberdeen.
Each practical covers the lectures of the week before it, and follows *Artificial Intelligence: A Modern Approach* (AIMA) by Russell and Norvig.

## Practicals

The folder names are stable labels and do not follow the teaching weeks one to one.
The week column gives the teaching week in which the session runs, and Blackboard links to each practical directly.
The Colab badge opens the notebook in Google Colab, where its first cell clones this repository, so nothing needs installing.

## Running the notebooks

Each notebook has an "Open in Colab" badge at the top and needs no installation that way; its first code cell clones this repository and installs what the notebook needs.
To work locally instead, install Python 3 and Jupyter, clone this repository, and install the packages in the root `requirements.txt` plus the `requirements.txt` of the week you are working on, if it has one.

## Getting help

Ask in the practical session, or on the course discussion board.
If you use an AI assistant, the `AGENTS.md` file in this repository tells it to help you reason about the exercise rather than write the solution for you.
